# CAMS — Engineering Document Collection

## Document control

These are controlled academic engineering
baselines and historical test documents.

Rookies and STHA are simulated organizations.

The baseline documents record planning and
design decisions at their respective phases.
They do not establish that later tests were
already executed at the time of approval.

For recorded test outcomes, see:

- [Testing Evidence](../TESTING-EVIDENCE.md)
- [Execution Excerpts](../../../evidence/public/PHASE6-EXECUTION-EXCERPTS.md)
